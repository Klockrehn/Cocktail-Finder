# Cocktail Finder

Cocktail Finder is an expanded and redesigned version of a cocktail application I originally created during my studies.

The original project was built as part of my coursework to practice working with APIs, JavaScript and dynamic web interfaces. This version takes that foundation further and turns it into a more complete and polished application focused on discovering cocktails and exploring recipes.

## Features

* **Cocktail Search**
  Search for cocktails and quickly find matching drinks.

* **Dynamic Cocktail Data**
  Cocktail information is retrieved dynamically through an external API.

* **Cocktail Details**
  Explore individual cocktails with their ingredients, measurements and preparation instructions.

* **Recipe Discovery**
  Browse cocktail recipes and discover new drinks to try.

* **Responsive Design**
  The interface adapts to different screen sizes for a consistent experience across desktop and mobile.

* **Interactive Interface**
  Search results and cocktail information are dynamically displayed through JavaScript.

* **Clean & Minimal UI**
  A simple interface designed to keep the focus on discovering and exploring cocktails.

## Technologies

* HTML5
* CSS3
* JavaScript
* REST API
